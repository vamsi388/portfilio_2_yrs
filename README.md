# Gundlapalle Vamsi — Portfolio

Personal portfolio site for an SAP BTP Full-Stack Developer, built with React and Vite.

**Live site:** _add your deployed URL here once it's live_

## Tech stack

- React 18
- Vite
- Plain CSS (custom properties, no framework)
- Formspree for the contact form

## Features

- Responsive, dark blueprint-themed design
- Animated architecture diagram (S/4HANA → BTP CAP → Fiori/UI5)
- Contact modal — recruiters can submit a JD directly to my inbox via Formspree
- Sections: About, Skills, Work Experience, Education

## Run locally

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
npm install
npm run dev
```

Open the printed localhost URL.

## Build for production

```bash
npm run build
```

Outputs static files to `dist/`, deployable to GitHub Pages, Netlify, or Vercel.
